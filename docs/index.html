  1. ตั้งค่าไว้ให้แล้วตาม dashboard.html เดิม: Realtime Database ที่ /sensor ฟิลด์ pm1_0, pm2_5, pm10
  2. ถ้า ESP32 ส่งฟิลด์อื่นเพิ่ม เช่น ก๊าซ อุณหภูมิ หรือพิกัด GPS ให้ใส่ชื่อฟิลด์นั้นใน fields (ฟิลด์ซ้อนใช้จุด เช่น "gps.lat")
  3. rtdbMode: "auto" (ค่าเริ่มต้น) อ่านประวัติจาก /history ถ้า ESP32 ส่งมา ไม่งั้นอ่านค่าล่าสุดจาก /sensor ถ้าเคยกดบันทึกการตั้งค่าไว้ก่อน ให้กด "ล้างค่าที่บันทึก" หนึ่งครั้ง
  4. ใส่รหัสสถานี Air4Thai ขอนแก่นใน air4thaiStation และรันสคริปต์ air4thai_to_firebase.py เพื่อให้มีค่าสถานีใน Firebase
